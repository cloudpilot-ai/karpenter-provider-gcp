# Code of Conduct

Karpenter GCP Cloud Provider adopts the [CNCF Community Code of Conduct](https://github.com/cncf/foundation/blob/main/code-of-conduct.md). This makes the adoption already stated in the README discoverable to contributors. It applies to participation in this project's repositories and community spaces.

## Confidential reporting: unresolved draft blocker

This draft does **not** establish a project-specific confidential reporting contact or an independent alternative for reports involving that contact. Maintainers must identify willing responders, publish both routes, and confirm private access and conflict handling before this policy is considered complete. Do not post confidential incident details in public issues or GitHub mentions.

The upstream Code of Conduct describes CNCF and Kubernetes reporting routes and [jurisdiction](https://github.com/cncf/foundation/blob/main/code-of-conduct/coc-committee-jurisdiction-policy.md). Adopting the code does not itself establish that a not-yet-admitted project is within a committee's jurisdiction, and this draft promises neither committee handling nor a response deadline. Reports concerning Kubernetes community spaces should follow that community's published reporting procedure.

The [governance proposal](GOVERNANCE.md#security-and-conduct-responsibilities) also identifies this gap.
