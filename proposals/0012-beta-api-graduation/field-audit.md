# Appendix: GCENodeClass / GKE field-and-feature audit

Source assessment for [proposal 0012](../0012-beta-api-graduation.md), 2026-11-16. This is a completed **source-level audit**, not evidence of live-cloud support or an implementation commitment.

## Baseline and evidence

- Provider behavior: `401e78cf` (`main`); [API definitions](../../pkg/apis/v1alpha1/gcenodeclass.go), [VM rendering](../../pkg/providers/instance/instance.go), [bootstrap overlays](../../pkg/providers/instance/metadata_bootstrap.go), [metadata inheritance](../../pkg/metadata/compute_metadata.go), [capacity/overhead](../../pkg/providers/instancetype/types.go), [networking](../../pkg/providers/instance/podrange.go), [fallback source pool](../../pkg/providers/nodepooltemplate/nodepooltemplate.go).
- Terraform Google **v8.11.0**, commit `67f96115b523ba050b11dad30237f14023667de8`: [47 root NodeConfig schema keys](https://github.com/hashicorp/terraform-provider-google/blob/67f96115b523ba050b11dad30237f14023667de8/google/services/container/node_config.go), [node-config/nested documentation](https://github.com/hashicorp/terraform-provider-google/blob/67f96115b523ba050b11dad30237f14023667de8/website/docs/r/container_cluster.html.markdown#nested_node_config), [pool/network documentation](https://github.com/hashicorp/terraform-provider-google/blob/67f96115b523ba050b11dad30237f14023667de8/website/docs/r/container_node_pool.html.markdown). Repository Terraform examples pin **6.28.0**; this audit intentionally uses the newer stable comparator, not a proposed dependency upgrade. Beta-only documentation is not proof of availability in that GA schema.
- [GKE v1 discovery snapshot](https://github.com/googleapis/google-api-go-client/blob/1179cf891c4a7c26ef6facb6956e82bfeb2ec32f/container/v1/container-api.json), commit `1179cf89`, supplements Terraform. REST presence does not establish feature GA, standalone-VM support or entitlement.

**Status:** C = explicit capability; P = partial/different semantics; H = source-dependent, no NodeClass control; M = missing; O = owned elsewhere; X = intentionally outside scope. C does not mean defaults/limits equal GKE or that tests were run.

**Timing:** B = resolve contract/shape/correctness before beta; A = additive candidate, not automatically a beta or stable blocker; V = validate the advertised envelope for beta (B9), then reconfirm/extend it for stable (S4); X = do not copy into NodeClass. “B” requires a decision/fix where necessary, not wholesale feature implementation. All recommendations remain subject to review.

## Actionable conclusions

| ID | Finding                                                                                                                                                                                                                                                                               | Recommendation / timing                                                                                                                                                                                                                                                                                                 |
|----|---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|-------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| G1 | `spec.labels` writes **GCE resource labels**; Terraform/GKE `labels` means Kubernetes labels, while `resource_labels` means GCE labels.                                                                                                                                               | **B:** prefer renaming the cloud-label field to `resourceLabels` in beta. Keep Kubernetes labels in NodePool metadata. If retaining the old name, explicitly approve/document the divergence now.                                                                                                                       |
| G2 | Disk API covers sizes/types/KMS/performance, but not GKE's universal defaulting. The renderer uses configured disks; only the swap path materializes a default boot disk. Its type preference starts with PD-standard, unlike current GKE's balanced-disk preference.                 | **B:** define required boot-disk/default behavior and PD/Hyperdisk selection policy (#755), including omitted size/type and boot cardinality. Retain `disks` as the richer provider abstraction unless a concrete incompatibility requires redesign.                                                                    |
| G3 | Many undeclared kubelet/kernel/GCFS settings can come from the selected source pool. They are not reliable declarative NodeClass support.                                                                                                                                             | **B:** define which settings are inherited, normalized or rejected and what source changes may alter. **V:** validate that supported defaults/security settings remain correct when source pool changes. Do not solve this by copying every GKE field.                                                                  |
| G4 | Top-level `confidentialInstanceType` differs from GKE's `confidential_nodes { enabled, confidential_instance_type }`.                                                                                                                                                                 | **B:** decide flat explicit opt-in versus a nested `confidentialNodes` contract before freeze; do not imply omitted/false semantics match GKE. PMU/confidential-storage additions remain A.                                                                                                                             |
| G5 | Kubelet fields use upstream names/types, but allow values outside GKE ranges; resource-affecting values also influence scheduler capacity/overhead.                                                                                                                                   | **B:** explicitly retain upstream-versus-GKE differences or tighten before beta, with conversion tests. Prioritize GC thresholds, parallel image pulls, eviction grace and shutdown semantics. New missing knobs are A.                                                                                                 |
| G6 | Primary subnet/private nodes, multiple secondary ranges and extra VM NICs exist; these are not multi-subnet selection or extra **pod** networks. VM rendering reads the older private-cluster flag, whereas GKE documents inheritance from `NetworkConfig.DefaultEnablePrivateNodes`. | **B:** fix/test effective private-node inheritance for both cluster forms, or prove legacy-field mirroring across the supported matrix; settle existing names and #569's additive extension path. Extra pod networks, bandwidth controls and independent secondary-NIC stack settings are A, with platform constraints. |
| G7 | Built-in-GPU shapes, driver choice and time sharing exist. Attached accelerator configuration, partition size/MIG and Fast Socket/GPUDirect do not.                                                                                                                                   | **B:** declare supported GPU contract and extension shape; **A:** #84/#483 and advanced networking. **V:** run hardware tests for whatever stable support actually advertises.                                                                                                                                          |
| G8 | OAuth scope is fixed to `cloud-platform`; metadata/WIF and image-streaming behavior partly depend on bootstrap source/cluster.                                                                                                                                                        | **B:** approve identity/default/trust policy; an `oauthScopes` field is not inherently required. **V:** validate WIF, credentials and supported image-streaming combinations before stable claims.                                                                                                                      |
| G9 | Alias and singular range are already deprecated; image-family precedence still matters for raw image IDs.                                                                                                                                                                             | **B:** remove deprecated beta surface, preserve alias meaning in conversion, and settle raw-ID/mixed-family bootstrap behavior.                                                                                                                                                                                         |

Most gaps appear additive at the schema level; individual feature designs must confirm compatibility, especially reservations, placement and networking. The immediate pre-beta work is **disposition of existing contracts and inheritance**, not filling every blank.

Existing overlay code is explicit: adding a Go API field alone does not automatically wire runtime behavior; the API comment suggesting automatic JSON merging is stale.

A missing one-to-one Terraform name is not automatically a missing feature.

## Milestone implications

**Beta:** decide G1–G9, implement necessary compatibility/default/security fixes, and test the retained contract. Recommended pre-beta changes are cloud-label naming cleanup, explicit boot-disk contract, deterministic/security-reviewed inheritance and removal of already-deprecated fields. Confidential nesting and network naming need decisions, not speculative empty blocks.

**Stable v1:** close the accepted beta scope with operational/adoption evidence; validate source-pool changes/WIF/image-streaming/hardware behavior actually advertised; retire eligible alpha compatibility; finalize stable API/support policy and test beta→v1 migration. Resolve any accepted remaining design blocker before freezing stable `v1`.

**Additive backlog:** missing sysctl/CPU/NUMA/logging controls, PMU, extra swap profiles, attached GPU/MIG, storage pools, sole tenancy/reservations and advanced networking require individual demand/design decisions. None is automatically a stable prerequisite merely because Terraform exposes it. Keep full parity as an audit baseline, not an endless milestone closure condition.
